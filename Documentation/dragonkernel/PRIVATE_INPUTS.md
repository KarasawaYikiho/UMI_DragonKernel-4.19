# 私密输入规则

## 禁止公开

- 输入名称、路径、版本、来源、下载地址和可识别标识
- 文件列表、大小、哈希、归档结构和解析元数据
- 原始分区镜像、密钥、签名材料和设备日志中的个人信息

这些信息不得进入 Git、提交信息、Issue、PR、公开日志、Actions 缓存、Artifact 元数据、Release 说明或公开文件名。

## 本地处理

- 输入保存在仓库外或忽略目录中。
- 路径只通过参数或环境变量传入，禁止写入源码。
- 本地输出只用于测试，不得上传 Releases。
- 日志只记录通用步骤和结果，不记录输入身份或内容清单。
- ROM 包使用 `prepare_rom_boot.sh <本地输入> <设备>` 写入忽略目录；Actions Artifact 使用 `validate_rom_artifact.sh <设备> <Artifact 目录> <本地输出>` 校验，不上传模板或重打包结果。

## CI 处理

正式打包需要私密输入时，只能通过批准的非公开通道临时注入：

- 输入不写入仓库和缓存；
- 工作流不打印名称、路径、哈希或文件列表；
- 使用后在 runner 生命周期结束时销毁；
- 公开产物只包含项目名称、时间、变体、设备代号和项目自身校验信息。

在安全注入通道确定前，CI 只允许构建公开源码产物，不允许发布正式刷机包。
