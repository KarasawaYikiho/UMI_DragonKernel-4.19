# 私密输入规则

目标 ROM、启动镜像和设备日志只允许在开发者本机处理。

## 禁止公开的内容

- ROM 名称、路径、版本、来源和下载地址；
- 文件名清单、大小、哈希和归档结构；
- 从 ROM 解析出的可识别元数据；
- 原始 `boot`、`vendor_boot`、`dtbo`、`vbmeta` 或其他分区镜像；
- 含账号、序列号、IMEI、网络信息或其他个人信息的日志。

## 本地处理约定

- 输入放在仓库外，或放在被忽略的 `.dragonkernel-private/`、`private/` 中。
- 本地产物写入被忽略的 `artifacts/`。
- 脚本通过命令行参数或环境变量接收路径，禁止硬编码私密路径。
- 公开构建只生成内核、DTB/DTBO 和不含私密 ramdisk 的中间产物。
- `boot.img`、Magisk 修补和最终刷机包只在本机完成。
- 对外仅公布 DragonKernel 版本、设备代号、变体、内核提交和项目自身产物校验和。
