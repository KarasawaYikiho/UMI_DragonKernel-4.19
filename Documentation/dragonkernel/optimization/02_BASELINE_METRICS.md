# 基线指标

| 场景 | 主要指标 | 安全护栏 |
|---|---|---|
| 日常交互 | 帧时间 P50/P95/P99、输入延迟、CPU/GPU 驻留、PSI | 温度、功耗、待机、唤醒、卡顿 |
| 游戏 | FPS/帧时间尾部、CPU/GPU/DDR 瓶颈、迁移 | thermal headroom、降频、功耗、电池温升 |
| 启动/加载 | 冷启动、资源等待、I/O tail、boost 重叠 | 不形成持续 floor，不阻止 idle/UFS 省电 |
| 后台 | LMKD、reclaim、refault、freezer、Binder 队列 | 通知、音频、下载、同步、恢复时延 |
| 电池 | 启动容量、FCC 学习、持久化、充放电曲线 | 电压、电流、认证、温度和充电 voter |

A/B 必须固定设备、ROM、温度、电量、亮度、网络与负载，至少覆盖系统桌面和澎湃超级岛。报告同时给出收益、回退和热/电代价，不用单一平均值替代尾部数据。
